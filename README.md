# StayFinder – Student Accommodation Website

## Project Overview

StayFinder is a student accommodation website designed to help students find comfortable, convenient and affordable places to stay while pursuing their education.

The website provides a simple platform where students can explore different accommodation options, compare sample prices, view room information and contact accommodation providers.

The main aim of this project is to make the process of finding student accommodation easier, faster and more convenient, particularly for students in Freetown, Sierra Leone.

## Project Objectives

- To provide students with information about available accommodation options.
- To make it easier for students to explore different types of rooms.
- To help students compare accommodation prices.
- To provide information about room facilities and locations.
- To create a user-friendly and responsive website.

## Website Features

1. **Home Page:** Introduces StayFinder and displays featured accommodation options.
2. **About Page:** Explains the background, mission, vision and values of StayFinder.
3. **Services Page:** Displays different accommodation options, including private rooms, shared rooms and student hostels.
4. **Search Results Page:** Presents accommodation listings with sample prices and room information.
5. **Room Details Page:** Provides additional information about accommodation, including facilities and descriptions.
6. **Contact Page:** Provides contact information and a message form for visitors.

## Technologies Used

- HTML5 – Used to structure the website.
- CSS3 – Used for styling, layout, colours and responsive design.
- Visual Studio Code – Used as the development environment.
- Figma – Used for website planning and interface design.
- Git and GitHub – Used for version control and project hosting.

## How to Run the Website

1. Download or clone the project to your computer.
2. Open the StayFinder project folder in Visual Studio Code.
3. Ensure that all HTML, CSS and image files are in their correct folders.
4. Open the index.html file.
5. Run the website using the Live Server extension or open index.html directly in a web browser.

## Target Audience

The primary target audience is students searching for accommodation near their schools, colleges and universities, particularly in Freetown, Sierra Leone.

## Project Limitations

This project is a front-end website demonstration developed using HTML and CSS only.

It does not currently include a database, user authentication, dynamic room searching or a working message submission system. The accommodation listings and prices are demonstration content.

## Future Improvements

- Add a database to store accommodation information.
- Implement functional room searching and filtering.
- Allow accommodation providers to upload room listings.
- Add student registration and login functionality.
- Integrate an online messaging system.
- Include an interactive location map.
